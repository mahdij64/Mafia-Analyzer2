# 🕵️ Mafia Analyzer 2 — تحلیل‌گر مافیا

اپلیکیشن اندروید کاملاً فارسی (RTL) برای ثبت و تحلیل هوشمند بازی مافیا:
ثبت مشاهدات، تارگت‌ها، آراء و محاسبه شفاف امتیاز «مشکوک بودن» هر بازیکن (۰ تا ۱۰۰)،
به‌همراه تحلیل هوش مصنوعی، مربی نطق، و حالت مخفی مافیا.

## ✨ قابلیت‌ها

- **میز بازی دایره‌ای**: ثبت تارگت‌ها با چیدمان صندلی دور میز، جابجایی و حذف بازیکن
- **الگوریتم شفاف سوءظن**: امتیاز ۰–۱۰۰ با لیست کامل دلایل (مثبت/منفی) و ضرایب قابل تنظیم
- **مراحل قفل‌شونده**: معارفه ← روز ۱ تا ۴ (بستن پرونده هر روز قبل از رفتن به روز بعد)
- **تحلیل هوش مصنوعی**: اتصال به هر سرویس سازگار با OpenAI (مثل **9router**) یا Gemini، با جایگزین محلی آفلاین
- **تست چت**: آزمایش سریع اتصال و مدل انتخابی داخل تنظیمات
- **مربی نطق (Speech Coach)**: متن نطق عامیانه متناسب با نقش شما
- **حالت مخفی مافیا (Stealth)**: فعال‌سازی با long-press روی عنوان اپ — یادداشت‌های سری و تاکتیک‌های گمراه‌سازی
- **گزارش‌ها**: گزارش روزانه، نقشه روابط، نمودار روند، گزارش نهایی و گزارش متنی قابل اشتراک
- **کاملاً آفلاین**: همه داده‌ها در Room روی دستگاه ذخیره می‌شوند

## 🤖 تنظیمات هوش مصنوعی (9router / هر سرویس OpenAI-compatible)

مسیر: **تب تنظیمات ← هوش مصنوعی**

1. **آدرس سرویس (Base URL)** از قبل با آدرس 9router پر شده است:
   `https://9router-production-e6c9.up.railway.app/v1`
2. **کلید API** خود را وارد کنید.
3. دکمه **«دریافت لیست مدل‌ها»** را بزنید — لیست مدل‌های سرویس در **کمبو (Dropdown)** نمایش داده می‌شود
   (امکان تایپ دستی نام مدل هم وجود دارد).
4. **Temperature** را در صورت نیاز تنظیم و **«ذخیره تنظیمات»** را بزنید.
5. با **تست چت** همان‌جا اتصال را آزمایش کنید.

پس از ذخیره، دکمه «شروع تحلیل با هوش مصنوعی» در تب گزارش‌ها از همین سرویس/مدل استفاده می‌کند.
اگر سرویس در دسترس نباشد، تحلیل هوشمند محلی (آفلاین) به‌صورت خودکار جایگزین می‌شود.

**ترتیب انتخاب موتور تحلیل:**
1. سرویس پیکربندی‌شده کاربر (OpenAI-compatible: `GET {base}/models` و `POST {base}/chat/completions`)
2. کلید Gemini از طریق فایل `.env` (متغیر `GEMINI_API_KEY` — توسط Secrets Gradle Plugin به `BuildConfig` تزریق می‌شود)
3. تحلیلگر محلی و آفلاین

> 🔒 کلید API فقط روی دستگاه شما (در دیتابیس Room) ذخیره می‌شود و تنها به همان Base URL واردشده ارسال می‌گردد.

## 🏗 ساختار پروژه

```
app/src/main/java/com/example/
├── data/
│   ├── ai/            # GeminiMafiaAnalyzer + OpenAiCompatClient (9router)
│   ├── local/         # Room: Entities, AppDao, AppDatabase (نسخه ۵ با مهاجرت‌ها)
│   ├── model/         # GameStage (معارفه، روز ۱..۴)
│   └── repository/    # MafiaRepository
├── domain/
│   ├── algorithm/     # SuspicionCalculator — قلب امتیازدهی شفاف
│   ├── model/         # StealthMisdirectionEngine — حالت مخفی مافیا
│   └── speech/        # SpeechCoachEngine — مربی نطق
└── ui/
    ├── components/    # کامپوننت‌های فارسی + نمودار روند
    ├── screens/       # ۱۶ اسکرین (میز دایره‌ای، رای‌گیری، گزارش‌ها، تنظیمات AI و…)
    ├── theme/         # پالت نوآر دارک
    └── viewmodel/     # MafiaViewModel (MVVM + Flow)
```

## 🔧 پیش‌نیازها و ساخت

- **JDK 17 یا بالاتر**
- **Android Studio** (یا Android SDK با `compileSdk 36`)

```bash
# بیلد دیباگ (keystore پیش‌فرض اندروید به‌صورت خودکار استفاده می‌شود)
./gradlew assembleDebug

# اجرای تست‌های واحد (الگوریتم سوءظن + کلاینت AI)
./gradlew testDebugUnitTest
```

### امضای Release

بیلد release به‌صورت خودکار بررسی می‌کند:

- فایل keystore در مسیر `KEYSTORE_PATH` (یا `my-upload-key.jks` در ریشه پروژه) **و**
- متغیرهای محیطی `STORE_PASSWORD` و `KEY_PASSWORD`

اگر همه موجود باشند، APK امضا می‌شود؛ در غیر این صورت **بدون خطا** یک APK unsigned ساخته می‌شود
(کانفیگ امضا به‌صورت شرطی در `app/build.gradle.kts` اعمال می‌گردد).

### کلید Gemini (اختیاری)

برای مسیر جایگزین Gemini، یک فایل `.env` در ریشه پروژه بسازید:

```
GEMINI_API_KEY=کلید_واقعی_شما
```

(الگو از `.env.example` کپی شود؛ فایل `.env` در `.gitignore` است.)
