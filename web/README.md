# تحلیل‌گر مافیا — نسخه وب (آفلاین)

پورت کامل اپ اندروید به یک **فایل HTML تک‌فایله** که بدون اینترنت، بدون نصب و بدون سرور روی هر گوشی/مرورگری کار می‌کند.

## اجرا

کافی است `index.html` را در مرورگر باز کنید (دوبار ضربه / لمس). هیچ وابستگی خارجی ندارد — همه CSS و JavaScript داخل همان یک فایل است.

برای اجرای روی گوشی بدون کامپیوتر: داخل برنامه به **تنظیمات ▸ داده‌ها ▸ «دانلود فایل HTML آفلاین»** بزنید؛ فایل مستقل ذخیره می‌شود و بعداً حتی از حافظه گوشی (file://) باز می‌شود.

## امکانات

- 🎯 میز دایره‌ای با ثبت تارگت‌ها (لمس = مبدأ، لمس بقیه = مقصد، نگه‌داشتن انگشت = پروفایل بازیکن)
- 🗳️ رأی‌گیری مرحله‌به‌مرحله (شامل ممتنع)
- 🧮 موتور محاسبه سوءظن — **پورت دقیق الگوریتم نسخه اندروید** (`SuspicionCalculator`) با همان ضرایب، سقف‌ها و برچسب‌ها
- ⚖️ تنظیم ضرایب الگوریتم (۵ تا ۶۰٪) برای هر بازی
- 📊 گزارش‌ها: رتبه‌بندی با عوامل شفاف، نمودار روند SVG، گزارش اشتراک‌گذاری
- 🗣 مربی نطق («چی بگم؟») متناسب با نقش و مرحله + متن کامل نطق عامیانه
- 🕶️ حالت مخفی مافیا (نگه‌داشتن انگشت روی عنوان): پنل گمراه‌سازی، شکاف‌های شهروندی و تاکتیک‌های انحرافی
- 👑 تعیین نقش خود و یاران مافیا، سناریو، حذف/احیای بازیکن
- 🎮 چند بازی همزمان + کپی بازی + بازی نمونه ۸ نفره
- 🤖 تنظیمات AI سازگار با OpenAI (پیش‌فرض: روتر 9router) با دریافت لیست مدل‌ها و چت تست — در صورت نبود اینترنت، **تحلیلگر محلی (آفلاین)** جایگزین می‌شود
- 💾 ذخیره خودکار روی دستگاه (localStorage) + پشتیبان JSON + بازیابی

## داده‌ها

همه داده‌ها در `localStorage` کلید `mafia_analyzer_web_v1` ذخیره می‌شوند و هرگز به هیچ سروری ارسال نمی‌شوند (به‌جز درخواست‌های اختیاری AI که خودتان کلیدش را وارد می‌کنید).
